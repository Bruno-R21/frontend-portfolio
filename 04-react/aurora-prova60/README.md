# Aurora — Painel de Produtos

Projeto da avaliação da Unidade Curricular **Desenvolvimento Web** — Programador Front-End (SENAI).

Painel de catálogo de uma loja, em React + Vite, consumindo a API JSONPlaceholder.

## Como rodar
```bash
npm install
npm run dev
```

## O que já está pronto
- **GET** — o catálogo é carregado da API ao abrir a página (`src/App.jsx`).
- Formulário (`ProdutoForm.jsx`) e cards de produto (`ProdutoCard.jsx`).

## O que você deve implementar
No arquivo `src/App.jsx`, complete as três funções marcadas com `TODO`:
- `handleCriar` → **POST**
- `handleAtualizar` → **PUT**
- `handleExcluir` → **DELETE**
